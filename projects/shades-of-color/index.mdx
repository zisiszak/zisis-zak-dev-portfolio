A side-project I created while working on [Biocard](../biocard) — specifically while experimenting with colour palette generation.

## Features

- 7 shade generation preset looks (Neutral, Vibrant, Faded, Slate, Extra Slate, RAW, BNW).
- Customisation sliders.
- Gradientify with 'Give Gradient'.
- Contrast ratio checks against every shade.
- Save/load configurations with a single string.
