A visual representation of a keyboard that responds to user input.

To improve responsiveness, I used some CSS tricks to alternate keycap styles. This removed the need to re-render keys, making for a very smooth experience.

## Features

- Alphanumeric and non-alphanumeric keys (TAB, CAPS-LOCK, CTRL, etc.) show when pressed.
- Visual updates to indicate key presses don't trigger re-renders of individual keys.
- Multiple key presses work as expected.
- Holding shift updates symbols (though CAPS-LOCK doesn't, whoops).
