React
View on Github

A React lightbox I created with the primary goal of it feeling satisfying to use with a mouse.

Features

  • Custom interaction animation implementation. Default parameters are tuned to feel intuitive and satisfying on mouse and keyboard, but custom swipeOptions can be set.
  • Toggleable infinite loop mode.
  • Preload a select number of images in advance.
