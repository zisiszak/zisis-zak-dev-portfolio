A React hook that is used for selection interactions for items placed in a grid. It emulates touchscreen drag-selection interactions for mouse users.

Testing on a Mac Studio (M1 Max, 32GB RAM) the drag selection still worked with 100,000 elements mapped out, albeit not so smoothly. At 10,000 elements, the drag selection was very usable.
